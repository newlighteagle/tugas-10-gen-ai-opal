Daftar Pertanyaan Kuis

Bank soal profesional mengenai Logika Komputer Dasar. Siap digunakan untuk ujian, tugas, atau latihan interaktif di kelas.

Pertanyaan 1

Unit terkecil dari data pada sistem biner yang hanya terdiri dari angka 0 dan 1 disebut dengan...

  • A Byte
  • B Bit
  • C Megabyte
  • D Sirkuit
Kunci Jawaban: B

Penjelasan: Bit atau Binary Digit adalah unit terkecil dari data dalam logika komputer yang merepresentasikan kondisi 0 atau 1.

Pertanyaan 2

Gerbang logika yang berfungsi untuk membalikkan nilai input (inverter) adalah...

  • A Gerbang AND
  • B Gerbang OR
  • C Gerbang NOT
  • D Gerbang XOR
Kunci Jawaban: C

Penjelasan: Gerbang NOT membalikkan nilai input; jika input 1 maka output 0, dan jika input 0 maka output 1.

Pertanyaan 3

Dalam gerbang logika AND, output akan bernilai 1 hanya jika...

  • A Salah satu input bernilai 1
  • B Semua input bernilai 0
  • C Semua input bernilai 1
  • D Salah satu input bernilai 0
Kunci Jawaban: C

Penjelasan: Aturan gerbang AND menyatakan bahwa output hanya akan benar (1) jika seluruh input yang masuk bernilai benar (1).

Pertanyaan 4

Berdasarkan tabel kebenaran, gerbang logika yang akan menghasilkan output 0 jika kedua inputnya sama (0-0 atau 1-1) adalah...

  • A Gerbang AND
  • B Gerbang OR
  • C Gerbang NOT
  • D Gerbang XOR
Kunci Jawaban: D

Penjelasan: Gerbang XOR (Exclusive OR) menghasilkan output 1 jika inputnya berbeda, dan menghasilkan 0 jika inputnya sama.

Pertanyaan 5

Berapakah hasil dari operasi logika 1 OR 0?

  • A 0
  • B 1
  • C 10
  • D Tidak terdefinisi
Kunci Jawaban: B

Penjelasan: Pada gerbang OR, output akan bernilai 1 jika salah satu atau seluruh input bernilai 1.

Pertanyaan 6

Dalam Aljabar Boolean, Hukum Null menyatakan bahwa A AND 0 (A . 0) akan menghasilkan...

  • A A
  • B 1
  • C 0
  • D Negasi A
Kunci Jawaban: C

Penjelasan: Hukum Null menyatakan bahwa apapun nilai A, jika dikalikan (AND) dengan 0, maka hasilnya akan selalu 0.

Pertanyaan 7

Simbol operator logika yang digunakan untuk mewakili gerbang OR dalam bahasa pemrograman seperti JavaScript adalah...

  • A &&
  • B !!
  • C ||
  • D !=
Kunci Jawaban: C

Penjelasan: Operator || digunakan untuk operasi logika OR, sedangkan && digunakan untuk AND dan ! untuk NOT.

Pertanyaan 8

Manakah dari pernyataan Aljabar Boolean berikut yang benar menurut Hukum Komplemen?

  • A A + 0 = A
  • B A + 1 = 1
  • C A . 1 = A
  • D A + (NOT A) = 1
Kunci Jawaban: D

Penjelasan: Hukum Komplemen menyatakan bahwa penjumlahan (OR) antara variabel dengan negasinya sendiri akan selalu menghasilkan 1.

Pertanyaan 9

Jika sebuah sistem memiliki logika (isLoggedIn && isAdmin), maka akses akan diberikan jika...

  • A Pengguna sudah login saja
  • B Pengguna adalah admin saja
  • C Pengguna sudah login dan pengguna adalah admin
  • D Pengguna tidak login tetapi seorang admin
Kunci Jawaban: C

Penjelasan: Operator && (AND) mengharuskan kedua kondisi di sisi kiri dan kanan bernilai benar agar seluruh pernyataan menjadi benar.

Pertanyaan 10

Sistem bilangan yang menjadi dasar bahasa ibu komputer karena hanya memiliki dua kondisi (ada arus atau tidak ada arus) adalah...

  • A Desimal
  • B Oktal
  • C Biner
  • D Heksadesimal
Kunci Jawaban: C

Penjelasan: Sistem biner (basis 2) menggunakan angka 0 dan 1 untuk merepresentasikan kondisi fisik sirkuit elektrik pada komputer.

Materi Pendukung

Logika komputer adalah cara komputer "berpikir" menggunakan pernyataan Benar (1) dan Salah (0).

Gerbang Dasar

  • • NOT: Membalikkan nilai.
  • • AND: 1 jika semua input 1.
  • • OR: 1 jika salah satu input 1.
  • • XOR: 1 jika input berbeda.

Hukum Boolean

  • • Identitas: A . 1 = A
  • • Null: A . 0 = 0
  • • Komplemen: A + NOT A = 1
